# pidgey-client

The Node.js client for the `/v1` API of [Pidgey](https://github.com/darthjee/pidgey), an
email-delivery service. It is in development: `0.1.0` is the first release line and the
package does not send email yet.

## Requirements

Node.js 22.12 or later.

## Repository

<https://github.com/darthjee/pidgey> (the package lives in `clients/nodejs/`).
